# CAN/CAN FD 工具实施计划

目标：纯前端、芯片无关的 CAN/CAN FD 位时序计算器，复用博客导航和主题，免费 Pages 部署。

架构：独立 ES module 计算核心、独立页面交互模块和 CSS；Hexo 工具布局引用静态模块，不增加运行时服务或第三方依赖。

- [x] 用已知值、穷举对照、输入边界验证计算核心。
- [x] 实现经典 CAN、FD 仲裁段、FD 数据段、BRS 联合计算，允许修改搜索范围和 SJW。
- [x] 新增工具首页与导航入口，说明公式、时钟输入含义及范围预设局限。
- [x] 执行测试、Hexo 构建、浏览器交互及移动排版检查。

算法：枚举 Prescaler 和总 TQ，选择给定组合中最接近目标采样点的有效 TSEG 分割。保留采样点等距的两个结果。按波特率误差、采样点偏差、总 TQ（降序）、Prescaler 排序并展示前 20 项。不是对控制器可行性的保证。

通用约束：SyncSeg=1 TQ；TSEG1 包含传播段和相位段1。SJW 固定为用户输入并要求不超过 TSEG2；其他硬件约束、时钟容差、传播延时、TDC、寄存器编码需用户核对。BRS 两段共享有效时钟，分别搜索；不设置未经依据的 8 倍倍率限制。

结果：名称 CanBitTimingTool，路径 /tools/can-bit-timing-tool/；采样点支持包含边界的范围筛选。浏览器已验证经典 CAN、BRS 两段、采样点 75–80%、TSEG 下限及非法上下限提示；修复恢复默认后阶段面板未同步的问题。390px 下无页面横向溢出。
