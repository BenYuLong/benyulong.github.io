# CanBitTimingTool 优化计划

用户授权实施上轮提出的优化，并完善范围预设。

- [x] 用有界最大堆保留可配置前 N 项，支持排序和显示数量；穷举对照验证。
- [x] 提取完整范围预设，包含 TSEG/Prescaler 上下限、步长、SJW 和采样点范围，保留时钟/目标波特率/目标采样点；提供扩展预设和无解诊断。
- [x] 输入错误定位到阶段及字段，增加持久化、URL 分享、逐行复制。
- [x] 验证测试、构建、浏览器交互与极端范围性能。

约束：不绑定芯片，不保证任意时钟波特率有解；不自动放宽用户选择的限制。保留独立阶段参数和本地计算，不增加服务。

验证：预设残留 SJW=100、采样点最小99.99%可重现无解，重选经典预设后恢复6个候选；无解诊断、错误字段标记、刷新恢复、分享还原、逐行复制与双阶段计算已在浏览器确认。同组极端参数从约3586ms降到509ms（本机 Node.js），堆仅保留 N 项。用户具体无解参数尚未提供，不断言所有无解情况均由残留条件导致。
